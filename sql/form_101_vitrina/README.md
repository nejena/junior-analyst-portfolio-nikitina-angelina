# Прототип витрины данных для формы 101 (ЦБ РФ)

Учебный проект в рамках курса «Аналитик DWH» от Neoflex (2026).

## Задача
Построить аналитическую витрину для автоматического формирования ежемесячной отчётности банка «Закрытие» перед ЦБ по форме 101 (оборотная ведомость по счетам бухучёта).

## Что сделано
- Собрала требования: чек-лист вопросов заказчику, User Story, Use Case, техническое задание.
- Разработала Source-to-Target маппинг — описала, как данные из 5 таблиц источника (PostgreSQL) преобразуются в витрину.
- Написала 5 SQL-запросов для получения актуальных счетов, остатков и оборотов; объединила их в единый CTE-прототип.
- Создала DDL витрины `f101_mart`, обосновала первичный ключ, проверила отсутствие дублей.
- Нашла и исправила ошибку в данных (перепутанные остатки по счёту 20202) с помощью UPDATE с самосоединением.
- Построила два дашборда в Yandex DataLens: контроль баланса и итоговый отчёт с остатками и оборотами.
- Подготовила и защитила презентацию результатов перед куратором и аналитиком.

## Инструменты и технологии
PostgreSQL, DBeaver, Excel, Draw.io, Yandex DataLens, PowerPoint

## Результат
Витрина формирует отчёт, полностью соответствующий эталону за май 2021 года.
