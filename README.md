### Python

- **Анализ вакансий HH.ru**  
  [папка проекта](https://github.com/nejena/junior-analyst-portfolio-nikitina-angelina/tree/main/python/hh-vacancies)  
  Проект анализирует вакансии разработчиков Python с HeadHunter: конвертация зарплат в рубли через API ЦБ, поиск вакансий с фильтрами, построение топов навыков и городов по уровню зарплат.  
  **Технологии:** Python 3, Pandas, Requests, API Центробанка РФ.

- **Визуализация многомерных данных с помощью лиц Чернова**  
  [папка проекта](https://github.com/nejena/junior-analyst-portfolio-nikitina-angelina/tree/main/python/pr2-chernoff-faces)  
  Анализ данных системы HVAC (отопление, вентиляция, кондиционирование) за 14 дней. Выполнена статистическая обработка, нормализация и построение асимметричных лиц Чернова для выявления аномальных дней.  
  **Технологии:** Python, Pandas, Matplotlib, NumPy.

- **Обнаружение финансового мошенничества**  
  [папка проекта](https://github.com/nejena/junior-analyst-portfolio-nikitina-angelina/tree/main/python/pr3-financial-fraud)  
  Исследование транзакционных данных для выявления подозрительных операций. Применены методы анализа данных и визуализации для поиска аномалий.  
  **Технологии:** Python, Pandas, Matplotlib, Scikit-learn (уточняется по коду).

- **Анализ данных киберфизической системы водоснабжения (SWaT)**  
  [папка проекта](https://github.com/nejena/junior-analyst-portfolio-nikitina-angelina/tree/main/python/swat-anomaly-detection)  
  Разведочный анализ данных сенсоров и исполнительных устройств, выявление паттернов атак, визуализация распределений, временных рядов, корреляционной матрицы и PCA.  
  **Ключевые выводы:** определены наиболее информативные признаки для обнаружения аномалий (расходомеры, уровнемер, анализатор, состояния насосов), выявлены выбросы и устойчивые изменения поведения системы во время атак.  
  **Технологии:** pandas, matplotlib, seaborn, scikit-learn.
